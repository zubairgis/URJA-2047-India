## Raster multipanel outputs

The full-resolution raster multipanel and LCC State/UT maps are part of the curated evidence package but are intentionally not placed in ordinary Git history. They should be released through Git LFS, a GitHub Release, institutional storage or a DOI repository once the final hosting route is selected.

All PESM figures must retain the interpretation caveat: **PESM is a preliminary lower-than-expected energy/activity screening signal, not a direct measure of electricity access or energy poverty.**
