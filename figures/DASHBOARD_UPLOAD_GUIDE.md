# Dashboard figure upload guide

The public dashboard is designed to display selected figures automatically when they are uploaded with the filenames below.

## 1. Main conceptual framework
Upload the corrected URJA-2047 workflow/framework figure here:

`figures/framework/urja2047_framework.png`

Recommended: PNG, 16:9 landscape, 1800–2400 px wide, white/light background. This figure appears in the **Research architecture** section.

## 2. Main PESM multipanel figure
Upload the publication-quality raster + State/UT multipanel here:

`figures/multipanel/urja2047_pesm_v02_multipanel_raster_state_LCC.png`

Recommended: PNG, 300–500 dpi export, preferably under about 8–10 MB for fast web loading. This appears in **Preliminary evidence**.

## 3. Additional PESM figures
Place PESM model maps, diagnostics and explainability graphics in:

`figures/pesm/`

Existing dashboard-linked files include:
- `figures/pesm/pesm_spatial_cv_r2_comparison.svg`
- `figures/pesm/pesm_structural_feature_importance.svg`

## 4. State/UT diagnostics
Place administrative maps and rankings in:

`figures/state_diagnostics/`

Existing dashboard-linked file:
- `figures/state_diagnostics/pesm_top15_state_screening.svg`

## 5. Renewable-energy figures
Place final solar, wind, complementarity, storage and ETFE graphics in:

`figures/renewable_energy/`

These can be connected to the dashboard as the Objective 3/4 evidence develops.

## File-naming rule
Use lowercase descriptive names with underscores. Avoid spaces. Keep the main web copies reasonably compressed; retain full-resolution publication originals separately if necessary.
