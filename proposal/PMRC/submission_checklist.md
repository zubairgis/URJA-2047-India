# PMRC Submission and Host-Institution Checklist

Use this checklist before the URJA-2047 proposal is sent to a host institution or uploaded to the PMRC portal. Items marked **Required before submission** should not remain unresolved in the final package.

## A. Administrative identity — Required before submission

- [ ] Confirm official PMRC call/year and submission deadline.
- [ ] Confirm final proposal title and thematic-area wording.
- [ ] Insert the exact name of the proposed PMRC host institution.
- [ ] Insert the host department/centre/school and proposed institutional coordinator, if required.
- [ ] Verify applicant name, designation, affiliation, nationality, contact details and ORCID/Scopus/Google Scholar identifiers.
- [ ] Attach the latest signed CV in the format required by the scheme.
- [ ] Confirm eligibility against the current PMRC rules.
- [ ] Add host-institution endorsement/forwarding letter in the prescribed format.
- [ ] Complete declarations on concurrent grants, employment, conflict of interest and research integrity.

## B. Scientific proposal — Required before submission

- [x] Primary thematic area clearly positioned as **Energy, Sustainability and Climate Change**.
- [x] National energy-security problem linked to sustainability, climate and equitable development.
- [x] USE → NEED → OPPORTUNITY → PATHWAY logic defined.
- [x] PESM, ESAG, ETFE and SEUPA concepts defined and differentiated.
- [x] Six linked research objectives provided.
- [x] 2047 demand formulation included.
- [x] S0–S4 scenario architecture included.
- [x] Cost–Carbon–Climate–Equity Pareto logic included.
- [x] National 1-km backbone and finer pilot design included.
- [x] Preliminary proof-of-concept results documented.
- [x] Bhuvan/ISRO and authoritative Indian data pathway documented.
- [x] Digital Twin and policy-translation strategy included.
- [x] Five-year work plan included.
- [x] Outputs/KPIs, capacity building, risks and open-science principles included.

## C. Evidence verification — Required before submission

- [ ] Re-check all current national petroleum/gas import statistics against PPAC/MoPNG.
- [ ] Re-check latest MNRE installed-capacity statistics.
- [ ] Re-check current CEA generation, transmission, resource-adequacy and storage planning numbers.
- [ ] Verify every Government of India citation and URL.
- [ ] Confirm Bhuvan/ISRO product availability and source-specific licence/redistribution conditions.
- [ ] Confirm the terminology and evidence maturity of preliminary renewable-resource products.
- [ ] Ensure PESM is never described as direct energy poverty, electricity access or consumption.
- [ ] Ensure preliminary results are clearly separated from research that will be performed during the Chair.

## D. Budget and institutional resources — Required before submission

- [ ] Obtain current PMRC budget ceilings and admissible heads.
- [ ] Prepare year-wise manpower plan.
- [ ] Prepare equipment/HPC/cloud/storage justification.
- [ ] Prepare field-validation and pilot-travel budget.
- [ ] Prepare Digital Twin/API/hosting budget.
- [ ] Prepare training-school, workshop and policy-engagement budget.
- [ ] Identify host-institution in-kind facilities: GIS/RS lab, servers/HPC, library/data access, office space, field support and administrative staff.
- [ ] Avoid requesting equipment already available from the host unless expansion is justified.

## E. Partnerships and letters — Strongly recommended

- [ ] Seek host-institution letter confirming strategic fit and institutional support.
- [ ] Seek letters/expressions of interest from relevant energy/geospatial partners where appropriate.
- [ ] Identify potential collaboration routes with MNRE/NIWE/CEA/NRSC-ISRO/PPAC/state agencies/energy utilities without claiming agreements that do not yet exist.
- [ ] Define data-sharing needs that may require MoUs after award.

## F. Pilot design — Before final scientific review

- [ ] Confirm transparent pilot-selection criteria.
- [ ] Avoid naming sites solely for convenience; justify representation of tribal/mountain, Northeast, arid, coastal/island and peri-urban systems.
- [ ] Define minimum field-validation variables for energy-service adequacy, infrastructure and renewable feasibility.
- [ ] Add ethics/data-governance protocol for any household, facility or utility microdata.

## G. Figures and tables — Required before submission

- [x] Conceptual-framework figure available as editable/vector SVG.
- [x] PESM spatial-CV figure available.
- [x] PESM feature-importance figure available.
- [x] State/UT preliminary screening figure available.
- [ ] Select final 3–5 figures for the proposal; avoid figure overload.
- [ ] Add final captions stating data source, period, resolution and interpretation limitation.
- [ ] Insert preliminary solar/wind/complementarity multipanel only if it improves the reviewer argument.
- [ ] Check all figures remain readable in printed A4/PDF format.

## H. Final document production — Required before submission

- [ ] Convert approved Markdown/source content to the exact PMRC template.
- [ ] Insert page limits, margins, fonts and section order required by the current call.
- [ ] Insert final budget tables and host details.
- [ ] Check in-text citations against the reference list.
- [ ] Run spelling, grammar, equation and abbreviation consistency checks.
- [ ] Remove track changes/comments and hidden metadata from submission DOCX/PDF where appropriate.
- [ ] Verify all figure/table numbering after conversion.
- [ ] Create a final archival PDF and checksum.
- [ ] Tag the submission version in GitHub, e.g. `pmrc-submission-v1.0`.

## I. Repository / reproducibility — Recommended before or shortly after submission

- [x] Public project repository created.
- [x] README, citation metadata, source registry and structured folders created.
- [x] Large-artifact manifest created.
- [x] Git LFS patterns configured for large binary research products.
- [x] Preliminary PESM tables, metadata and validation evidence versioned.
- [x] Reproducibility workflow documented.
- [ ] Add final Colab/GEE notebooks after cleaning credentials/project-specific temporary paths.
- [ ] Add software environment files.
- [ ] Publish large rasters via approved storage/DOI/release route when licensing permits.

## Final gate

The proposal is scientifically mature enough for host-institution discussion now. **Do not label it administratively ready for PMRC submission until the current PMRC template/rules, host institution, institutional endorsement and scheme-compliant budget are inserted and verified.**
