# PMRC Proposal

This folder contains the version-controlled source material for the **URJA-2047 India** Prime Minister Research Chair proposal under the thematic area **Energy, Sustainability and Climate Change**.

## Main files

- [`URJA2047_PMRC_Research_Chair_Proposal.md`](URJA2047_PMRC_Research_Chair_Proposal.md) — submission-ready proposal source.
- [`executive_summary.md`](executive_summary.md) — concise reviewer/host-institution summary.
- [`proposal_overview.md`](proposal_overview.md) — concept, positioning and preliminary-evidence overview.

## Submission artifacts

The formatted DOCX/PDF versions should be generated from the approved proposal source and stored as release/host-institution submission artifacts. Large/binary files should use Git LFS or a release/DOI repository rather than ordinary Git history.

## Before final submission

Replace the host-institution placeholder, insert the scheme-compliant budget, confirm PMRC administrative fields and declarations, and verify all current national statistics against the cited Government of India sources on the submission date.

The proposal deliberately describes PESM as a preliminary screening signal; policy claims about energy deprivation require independent ESAG and socioeconomic/service validation during the Chair programme.
